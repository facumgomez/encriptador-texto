# 🔐 Encriptador de Texto

Aplicación web desarrollada como parte de un desafío de programación que permite encriptar y desencriptar texto utilizando reglas específicas de transformación.

---

## 📌 Descripción

Este proyecto permite:

- Encriptar texto ingresado por el usuario.
- Desencriptar texto previamente encriptado.
- Copiar el resultado al portapapeles.
- Utilizar una interfaz simple, clara y responsive.

El objetivo es practicar lógica de programación, manipulación del DOM y desarrollo frontend con HTML, CSS y JavaScript.

## 🔎 Reglas de encriptación

El sistema utiliza las siguientes reglas:

- `e` → `enter`
- `i` → `imes`
- `a` → `ai`
- `o` → `ober`
- `u` → `ufat`

Estas transformaciones permiten codificar y decodificar mensajes fácilmente.

---

## ⚙ Funcionalidades

- Encriptar texto.
- Desencriptar texto.
- Copiar resultado al portapapeles.
- Validación de entrada (solo minúsculas).
- Diseño adaptable a distintos dispositivos.
